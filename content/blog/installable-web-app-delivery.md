# Installable web apps for delivery: when app stores are not the first door

Not every customer will fight an app store today. Links shared on WhatsApp still drive demand. Installable web apps let people pin a shopfront without the store friction — if performance and offline manners are respectable.

## Definition

An **installable web ordering app** is a mobile web experience that can be added to the home screen and carry cart, menu, and tracking without a mandatory store install.

## What doing nothing already costs

| Leak | What you already pay |
|------|----------------------|
| Store-only launch | Lost link traffic |
| Heavy pages | Drop-off on 3G |
| No install path | Low return |
| Desktop mindset | Thumb failure |

Escape, not shame: staff improvising were the system. Give them a calmer one.

## Framework

1. Ship mobile-fast web
2. Offer add-to-home-screen
3. Keep cart durable
4. Test on mid-range Androids
5. Share deep links on WhatsApp

## Believable operational scenario

A promo hits a WhatsApp group. The store listing is slow to find. A link to an installable web app converts the lunch window.

## Common mistakes

- Assuming store installs first
- Ignoring mid-range phones
- Breaking back-button carts



## Tools that help

PWA patterns, responsive menu/cart, tracking pages.


## Checklist

- [ ] Loss written as one dated sentence
- [ ] Object and ID defined
- [ ] Capture and review roles named
- [ ] Two-week parallel run
- [ ] Success = time or disputes, not logins

## Fourteen-day path

Date the loss, define the object, capture new events, compare disputes, retire the shadow process for pilot scope. Simplify if calm does not improve.

## Why this leak compounds weekly

Improvisations multiply. New staff learn workarounds. Calm surfaces hide disputes until reconstruction is forced.

## What good looks like after two weeks

Faster capture, mid-week review, leave-safe records, leadership answers without calling three people.

## Metrics that matter

Time to answer, disputes, exception age, close or report length. Ignore vanity logins.

## Kinshasa / Nairobi notes

Mobile money, WhatsApp front door, patchy signal. Localise labels; keep object discipline.

## How AI changes this

AI reminds and summarises. It does not invent proof. Design evidence rules first.
